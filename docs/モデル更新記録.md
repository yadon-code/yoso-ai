# モデル更新記録

週1回の自動学習（`.github/workflows/train.yml`）で、モデルを差し替えた記録です。1行＝1回。

- 指標: 1着モデルは「評価期間（直近30日）で、1着になった艇の1着確率の対数損失（logloss。小さいほど良い）」と AUC。判定は logloss で行う。
- 差し替えの線: 今のモデルより logloss が低く、差が偶然のばらつきより大きく（艇ごとの差の平均 − 2×標準誤差 > 0）、差が 0.001 以上。満たさなければ見送り（今のモデルのまま）。
- 学習期間は「学習に使った期間」で、木の数を決めるために使った期間も含む。評価期間は学習に使っていない。
