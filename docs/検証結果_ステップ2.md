# ステップ2 検証結果（2026年11月8日）

## やったこと
1. 2026年8月1日〜11月6日の全レース（14,895レース）について、3連単120通りの**締切時オッズ**を公式サイトから集めた
2. レース前にわかる情報から、各艇の**1着確率**を出すAIモデルを作った（LightGBM）
   - 学習：2024年1月〜2026年4月 / 調整：2026年5〜7月
   - 効いている情報：艇番（コース）、選手のその枠での直近成績、全国勝率の差、展示タイムの差
3. 1着確率から**3連単120通りの確率**を計算し、オッズと比べて「期待値（確率×オッズ）が高い買い目」だけを買う作戦を試した
4. オッズ期間の前半（8/1〜9/18）で作戦の細かい設定を決め、**後半（9/19〜11/6）にそのまま当てはめて**成績を見た

## 結果（後半＝テスト期間の回収率）

| 買い方 | 回収率 | 買った点数 |
|---|---|---|
| 毎レース全120通り買う | 61% | 885,600 |
| 毎レース一番人気の3連単を1点だけ買う | 74% | 7,380 |
| **AIで割安と判断した買い目だけ買う（今回の作戦）** | **90%** | 1,742 |
| 同上（別の設定。点数多め） | 91% | 7,690 |

## わかったこと
- AIで選ぶと、何も考えずに買うより**回収率がはっきり上がる**（61〜74% → 約90%）
- ただし**まだ100%には届いていない**。今のままお金をかけるのはおすすめしません
- 確率の正確さだけで比べると、まだ**市場のオッズのほうが少し正確**。AIはオッズの「ズレ」を一部見つけられているが、控除率25%を超えるほどではない

## 注意点
- 使ったのは締切時の最終オッズ。実際に買うときは締切数分前のオッズしか見えないため、本番は少し悪くなる可能性がある
- テスト期間は約7週間分。短い期間の回収率は運でかなりぶれるので、もっと長い期間での確認が必要

## 次に効きそうな改善
1. **直前情報を足す**：展示のスタートタイミング、チルト角度、部品交換、周回展示タイム（プロの予想家が重視する情報）
2. **今節の成績を足す**：その開催での調子
3. **2着・3着を直接予想するモデル**：今は1着確率から計算で出しているので、ここを専用モデルにする
4. オッズの期間を延ばして、検証をより確かなものにする
