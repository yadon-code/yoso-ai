# グレードレース（SG・G1）の分析（2026-11-12）

グレードは公式サイト「本日のレース」の表示から集めた（`src/download_grade.py` → `data/csv/grades.csv`、2024/1〜）。
分析は `src/analyze_grade.py`（学習〜2026-03、調整 4〜6月、テスト 7月〜）。

## レース数
| | 2024 | 2025 | 2026(〜11/12) |
|---|---|---|---|
| SG | 570 | 576 | 432 |
| G1 | 2,627 | 2,612 | 2,412 |
| 一般 | 47,013 | 47,174 | 40,837 |

SG・G1 は全体の約5%（1年に約3,200レース）。オッズがある期間（2025/1〜）では 5,950レース、
そのうち学習に使っていない「正直に成績を測れる」期間は 1,814レースしかない。

## 分かったこと
- 1号艇がとても強い：1着率 SG 64% / G1 63% / 一般 54%。
- しかも市場（オッズ）は SG の1号艇を約5ポイント低く見ている（一般は約2ポイント）。
  1号艇1着の3連単を全部買うと回収率 SG 81% / G1 74% / 一般 70%。SGは「歪み」が大きいが、これだけでは100%に届かない。
- 今のAI（第2段階）を SG・G1 だけで見ると：期待値>1・オッズ100倍まで 413点で回収率90%（的中8回）、
  300倍まで 1,449点で116%（的中15回）。点数が少なく、どちらも「たまたま」の範囲。
- グレードやレースの種類（予選・準優・優勝戦など）をAIにそのまま足しても、SG・G1 の精度は良くならなかった（データが少なすぎて学べない）。

## 結論
グレードレースだけで別のAIを一から作るのはデータが足りない。今のAI（全レースで学習）を土台にして、
「SGの1号艇の過小評価」のような少数の分かりやすい補正だけをグレード用に足し、エア投票で別枠に記録していくのが現実的。

## 追加検証：2019年からのデータで（2026-11-13）
公式サイトに残っている 2019年1月以降の SG・G1 のオッズと直前情報を集め（`src/collect_grade_history.py`）、
SG・G1 のオッズ付きレースは 約6,000 → 25,187 に増えた。第1段階AIの予想も2020年以降に付けた（`OOF_START=2020-01-01 OOF_FILE=oof_predictions_long.csv python src/train.py oof`）。

1年ずつ「前の年までで学習 → その年を予想」を2021〜2026年で繰り返した（`src/exp_grade_long.py`、SG・G1 18,867レース）:

| | 3連単の対数損失 | 期待値>1・100倍まで | 期待値>1・300倍まで |
|---|---|---|---|
| 市場（オッズ） | 3.8428 | — | — |
| A 今のAI | 3.8390 | 3,991点 105%（的中82） | 14,779点 92% |
| B グレード・レース種類を特徴量に追加 | 3.8392 | 4,871点 103%（的中93） | 18,521点 89% |
| C 1号艇をグレード別に補正 | 3.8397 | 4,111点 110%（的中90） | 13,920点 88% |

- 今のAIは、SG・G1でも毎年わずかに市場より正確（6年すべてで対数損失が市場より小さい）。ただし差は一般戦より小さい。
- 本番と同じ「100倍まで」で回収率105%。的中82回なのでブレは±12%ほどあり、100%超えとはまだ言えない。300倍まで広げると92%。
- B・C は A と差がない（C の110%も誤差の範囲。1号艇の補正の大きさは年によって −0.03〜+0.19 とばらつく）。
- 結論：SG・G1 も今のAI・今の買い方（100倍まで）のままにする。補正は入れない。
