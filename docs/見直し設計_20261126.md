## まず要点（ここだけ読めば大筋が分かります）

1. **今の実力は「回収率 85%前後」とみるのが正直**。過去の検証の 103%（確定オッズで計算）は、本番の「5分前のオッズで買う」条件では約15%甘い（#12）。全通り買いは 73〜74%。
2. **いちばん大きな落とし穴は、学習と本番で条件が違うこと**。①確定オッズで学び5分前で買う ②学習の気象はレース後の記録、本番はレース前の値 ③学習データには「部品交換・プロペラ」が空なのに本番は入っている ④買い方の設定（期待値1.0・100倍まで）はテスト期間の成績を見たあとに決めた疑い。
3. **第2段階の学習に使った大きなデータ（確定オッズ・直前情報・オリジナル展示 約10万レース）が、Mac にも GitHub のキャッシュにも無い**。作業したクラウドの作業場にしか無かったようです。作り直すには取り直し（無料・数日〜1週間の取得）が必要。**最初にこれを確かめて、外付けディスクなど消えない所に置く**。
4. 特徴量は 第1段階 62個・第2段階 30個・展開 82個。**足りないのは「選手の期別成績（コース別の1着率・ST・進入）」「前付け・枠なりのくせ」「風を場の向きで見た追い風/向かい風」「レースの種類（予選・準優・優勝・進入固定）とグレード」「ナイター・時刻」「潮」「オッズの動き」「他の券種のオッズ」** など。ほとんど公式から無料で取れます。
5. **2本立ては「土台（データ・特徴量・着順確率）は共有、使い方を分ける」がおすすめ**。的中AI＝着順の確率をできるだけ正確に出すAI。回収率AI＝その確率に「確定オッズの予想」を掛けて、期待値が十分高いものだけ買うAI。
6. 回収率AIのカギは **「5分前の時点で、確定オッズがいくらになるか」を当てる部品**。そのための5分前オッズは 11/11 から1日約150レースずつたまっていて、**3か月（2月ごろ）で約1.3万レース**。それまでは「期待値帯ごとの割引（約15%）」で代用。
7. 確かめ方は **「1か月ずつずらしながら学習→翌月で試す」＋「最後の3か月は決めるまで絶対に見ない」**。本番は今の予想を止めずに、新しい2本を**影の記録（通知なし）で横に並べて**3か月比べる。
8. **お金のかかるものは基本なし**（公式データ・Mac・公開リポジトリの Actions は無料）。かかる可能性があるのは「リポジトリを非公開にする（Actions が有料になる）」「有料データ」で、どちらも今はおすすめしません。**実際のお金を賭けるのは、回収率の95%幅の下の端が100%を超えるまでおすすめしません。**

## 3. 2本立ての設計案

### 3-1. 全体の形（おすすめ：土台は共有・出口を分ける）

```
[データの土台]  番組表・成績・直前情報・オリ展・オッズ（確定と5分前）・期別成績・潮
      │   すべてに「いつ分かったか」の時刻を付ける（締切5分前より後の情報は使わない）
      ▼
[特徴量の土台]  学習と本番で同じ関数（同じ日を両方で作って一致を確かめるテストを置く）
      │
      ├─▶ 着順確率モデル（オッズなし版）   … 朝の予想・展示前用
      └─▶ 着順確率モデル（5分前オッズあり版）… 的中AI の本体。回収率AI の材料にもなる
                 │
       ┌─────────┴──────────┐
  【的中AI】                【回収率AI】
  確率の高い順に出すだけ     ＋確定オッズの予想 → 期待値 → 買う/買わない → 金額
```

- データ・特徴量・着順確率は**共有**（作るのも直すのも1か所で済み、比べやすい）。
- 回収率AI だけの部品：「確定オッズの予想」「買う基準」「資金配分」。
- のちの試し：回収率AI 用に「オッズの高い所の当てはまりを重く見る」学習を別に作って比べる（#8 で正確さ≠儲けだったため）。

### 3-2. 的中AI

| 項目 | 案 |
|---|---|
| 当てるもの | 6艇の**着順の確率**（1着・2着・3着の並び120通りまで）。まず「1着」→「2着・3着は条件付き」（1着が決まったとき残りの誰が2着か）の順に作り、ハーヴィル式の近似をやめる |
| 作り | 段階1：LightGBM（艇ごと）。段階2：レース単位で順位を学ぶ形（ランキング学習／条件付きロジット）と比べる。入力に5分前オッズを入れる版と入れない版 |
| 出すもの | 券種ごとの「当たりやすい順」：単勝（本命1点）、2連単・2連複の上位、3連単の上位 N 点、拡連複。**「この点数で的中率は何%」の表**も出す（例：3連単上位6点で的中◯%） |
| 物差し | 対数損失（1着・2連単・3連単それぞれ）、ブライアースコア、上位 N 点の的中率、**確率の当たり具合**（「30%」と言ったものが本当に30%来るか）。**いつも「5分前オッズそのもの」と比べ、勝っているか**を見る |
| 合格の線 | 時期ずらしの全期間で、5分前オッズより対数損失が小さい（差 − 2×標準誤差 > 0） |

注意：的中AI は「当たる」けれど「儲かる」とは限りません（本命ほど配当が低い）。通知では回収率AI と混ぜず、別の枠にします。

### 3-3. 回収率AI

| 項目 | 案 |
|---|---|
| 確率 | 的中AI の「5分前オッズあり版」の120通りの確率（確率の当たり具合を、オッズの高い所でも確かめて直す） |
| **確定オッズの予想** | 5分前オッズ・締切までの秒数・人気順・AI と市場の差（#12 で「お得に見える所ほど下がる」）・場・時刻・グレード・券種から、「確定÷5分前」を予想する。学習には 11/11 からためている5分前と確定の組を使う（3,000レースで試作、1万レース以上で本番級） |
| それまでのつなぎ | #12 の「期待値帯ごとの下がり方」（1.0〜1.1 で0.80倍、1.1〜1.3 で0.64倍など）で割り引く。**今の本番の「期待値>1.0」は実質0.85前後なので、基準の見直しは急ぎ** |
| 期待値 | 確率 × 予想した確定オッズ。控除率は券種で違う（公式の払戻率で要確認：単勝・複勝は高め、ほかは75%）ので、券種ごとに見る |
| 買う基準 | 「期待値の下の見積もり（ぶれを引いた値）> 1」の買い目だけ。オッズの上限は券種ごとに時期ずらしの検証で決める。1レースの点数の上限も置く |
| 資金配分 | まずは **定額100円**（比べやすい）。次に「ケリー基準の1/8〜1/4」（期待値が高く確率が高いほど多め）を、1レース・1日の上限付きで比べる |
| 物差し | 回収率（日ごとに引き直す方法の95%幅）、**最大の連敗と最大の落ち込み**、**月ごとのぶれ**、的中回数、**買った時のオッズと確定オッズの比（CLV。1を超えれば市場より先に動けている）**、期待値の見積もりと実際の差 |
| 合格の線 | 決めるまで見ない最後の期間で、**95%幅の下の端が100%以上**、かつ的中100回以上。満たすまで実際のお金は賭けない |

「5分前」をどう扱うか（あわせて試す）：
1. 確定オッズの予想（上）……本命。
2. **予想する時刻を締切に近づける**（例：2分前）。エア投票なら購入にかかる時間は要らないので、ずれは小さくなるはず。ただし GitHub の動きの遅れとの兼ね合いがある。
3. 5分前に加えて **10分前・2分前・1分前のオッズも保存**し、動きそのものを材料にする（過去分は取れないので早く始めるほど得）。

## 4. 確かめ方

### 4-1. 時間で区切った検証（ずらしながら）
- **1か月ずつずらす**：「その月の前まで」で学習 → その月を予想、を 2025-01 から毎月くり返し、全部つないで成績を出す。木の数を決める期間は学習の最後の1〜2か月から取る（テスト月は使わない）。
- 第2段階に入れる第1段階の確率も、同じ「その前まで」で作ったもの（今の oof と同じ考え）。
- **最後の3か月は「金庫の期間」**：設定をすべて決めて紙に書いてから、1回だけ開ける。開けたあとに設定を変えたら、次の3か月が新しい金庫。
- 試した設定の数を記録する。たくさん試すほど「たまたま良かった」が混ざるので、合格の線は「95%幅の下の端」で判定。

### 4-2. 未来の情報を入れない決まり（チェックリスト）
1. 特徴量ごとに「いつ分かるか」（前日／朝／展示後／5分前）を表にし、5分前より後のものは使わない（気象は直前情報の値。競走成績の値は使わない）。
2. **学習と本番で同じ関数**を使い、「過去の1日を本番のやり方で作った特徴量」と「学習用に作った特徴量」が一致するかのテストを置く（ずれ C のような空欄の違いもここで見つかる）。
3. 欠ける列（江戸川のオリ展など）は、学習でも同じように欠けさせる。
4. 選手の「直近◯走」は、そのレースより前のレースだけ（今のやり方は OK）。期別成績は「公表された日」以降だけ使う。
5. オッズは「確定」と「5分前」を名前で分け、確定は答え合わせ（払戻）と確定オッズ予想の学習の答えにだけ使う。

### 4-3. 手元での再現
- Mac で、同じデータ・同じ乱数で動かすと同じ数字が出ること。データのファイルごとの指紋（ハッシュ）を結果に一緒に残す。
- 最初の仕事は **今の v2 を新しい検証の仕組みで動かして、#8・#12 の数字が再現できるか**（できなければ、どこが違うかを先に直す）。

### 4-4. 本番での比べ方（エア投票）
- 今の本番（v2）はそのまま。新しい的中AI・回収率AI は **同じレース・同じ5分前オッズ** で予想して、別の `model` 名でエア投票に記録（**通知はしない＝影の記録**）。
- 同じレースどうしで比べる：対数損失の差（レースごとの差の平均と標準誤差）、回収率と95%幅、CLV、的中率。
- 判断の目安：**3か月 または 的中100回** のどちらか遅い方。
- 本番に効く変更（live.py に影の記録を足す）は、決まりどおり別の AI が点検してから入れる。

### 正直な見通し
- 3連単の控除率は25%。市場（特に締切直前のお金）はかなり正確で、AI が確定オッズに勝てている幅は対数損失でわずか（−0.003〜−0.012）です。
