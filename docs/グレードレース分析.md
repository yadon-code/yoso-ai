# グレードレース（SG・G1）の分析（2026-11-12）

グレードは公式サイト「本日のレース」の表示から集めた（`src/download_grade.py` → `data/csv/grades.csv`、2024/1〜）。
分析は `src/analyze_grade.py`（学習〜2026-03、調整 4〜6月、テスト 7月〜）。

## レース数
| | 2024 | 2025 | 2026(〜11/12) |
|---|---|---|---|
| SG | 570 | 576 | 432 |
| G1 | 2,627 | 2,612 | 2,412 |
| 一般 | 47,013 | 47,174 | 40,837 |

SG・G1 は全体の約5%（1年に約3,200レース）。オッズがある期間（2025/1〜）では 5,950レース、
そのうち学習に使っていない「正直に成績を測れる」期間は 1,814レースしかない。

## 分かったこと
- 1号艇がとても強い：1着率 SG 64% / G1 63% / 一般 54%。
- しかも市場（オッズ）は SG の1号艇を約5ポイント低く見ている（一般は約2ポイント）。
  1号艇1着の3連単を全部買うと回収率 SG 81% / G1 74% / 一般 70%。SGは「歪み」が大きいが、これだけでは100%に届かない。
- 今のAI（第2段階）を SG・G1 だけで見ると：期待値>1・オッズ100倍まで 413点で回収率90%（的中8回）、
  300倍まで 1,449点で116%（的中15回）。点数が少なく、どちらも「たまたま」の範囲。
- グレードやレースの種類（予選・準優・優勝戦など）をAIにそのまま足しても、SG・G1 の精度は良くならなかった（データが少なすぎて学べない）。

## 結論
グレードレースだけで別のAIを一から作るのはデータが足りない。今のAI（全レースで学習）を土台にして、
「SGの1号艇の過小評価」のような少数の分かりやすい補正だけをグレード用に足し、エア投票で別枠に記録していくのが現実的。
