# 新しいAI（v3）段階2の結果：市場を出発点にした的中AI（2026-11-28）

対象：2025-01〜2026-08 の 90,187 レース。1か月ずつずらして「その前まで」で学習→翌月を予想（20回）。
**金庫（2026-09〜）は開けていません。** 幅はすべて「日ごとに引き直す」方法の95%幅。ログは `~/Desktop/競艇AI/data_full/logs/stage2_*.log`。

## まず要点

1. **全期間で、市場（確定オッズ）にはっきり勝った**。3連単の対数損失で市場より **−0.0218 [−0.0228, −0.0206]**、1着で −0.0094 [−0.0102, −0.0087]。95%幅が0をまたがない。今の本番 v2（−0.011）の約2倍の差。
2. 当てる順番でも少しだけ上：本命の1着的中率 58.3%（市場 58.1%）、3連単上位6点 41.5%（市場 41.0%）。ただしこちらは差が小さく、95%幅が重なっている。
3. **回収率の表は「確定オッズで買えた場合」の上限の目安**。3連単・期待値1.0超・50倍まで、で 2025年 107.9% [100.8, 115.2]、それを当てはめた 2026年1〜8月 110.8% [102.9, 118.3]。
4. **本番（締切5分前に買う）では、これより大きく下がる見込み**。#12 では「確定オッズで決めた場合」より「5分前で決めた場合」が約15〜17ポイント低かった。そのまま当てはめると 3連単は 93〜95% 前後になり、**100% を超えるとはまだ言えない**。
5. 次：締切前オッズ（11/26 から記録中）を使って「5分前で決めて確定で払い戻す」本番と同じ形で測る。それまでは本番の予想・通知は変えない。

## 3. 回収率の表（3連単。期待値が基準を超えた買い目を100円ずつ）

### 大事な前提：この表は「確定オッズで買えた場合」
- AI の出発点も、買うかどうかの判断も、払い戻しも、**すべて締切後の確定オッズ**で計算している（過去には確定オッズしか無いため）。
- 本番は締切の約5分前に、5分前のオッズで決める。#12 では「お得に見える買い目ほど、最後の5分でオッズが下がる」ことが分かっていて、確定オッズで決めた場合より **約15〜17ポイント** 回収率が低かった。
- さらに、5分前の市場は確定オッズよりかなり不正確（#12：対数損失 +0.08）。AI の出発点も5分前のオッズになるので、AI 自体の正確さも下がる。

### 本番（5分前で買う）だとどうなりそうか
- 確定オッズで買えた場合の 106〜111% から、#12 の差（約15〜17ポイント）を引くと **91〜96% くらい**。今の本番の実力（#12 で 85% 前後）よりは良さそうだが、**100% を超えるとは言えない**。
- これは目安で、本当の数字は「5分前で決めて、確定で払い戻す」形で測るしかない。締切前オッズは 11/26 から毎日約840回（約168レース×5回）記録しているので、3,000レースたまる **12月中旬〜下旬** に一度測れる（ただし数週間分なので幅は広い）。
