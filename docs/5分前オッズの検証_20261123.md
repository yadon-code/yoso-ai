# 5分前オッズで買うと本当はどうなるか（2026-11-23）

これまでの検証は「確定オッズを見て買い目を決める」計算でした。本番は締切の約5分前のオッズしか見えません。
11/11〜11/16 に保存した5分前オッズ（877レース）で、本番と同じ買い方の成績を初めて計算しました。
計算: `src/exp_pre_odds.py`（本番の第2段階モデル。対象日は学習に使っていない日）

## 分かったこと

1. 5分前のオッズは、確定オッズよりずっと不正確（対数損失 +0.080）。AIが5分前オッズを直しても、確定オッズには届かない（+0.053）。
   最後の5分で入るお金が、いちばん情報を持っている。
2. AIが「お得」と判定した買い目ほど、最後の5分でオッズが下がる。期待値1.0〜1.1の買い目は確定までに 0.80倍、1.1〜1.3 は 0.64倍。
   確定オッズで計算し直すと、期待値は 0.99〜1.06 → ほぼ消える。
3. 本番と同じ買い方（5分前に期待値1.0超・100倍まで）の回収率は 86%（342点、95%幅 47〜137%）。
   点数の多い「期待値0.9〜1.0」の帯は 80%（2,146点、95%幅 67〜95%）で、AIの見積もり（約95%）より15ポイントほど低い。
   → 5分前オッズで計算した期待値は、実際より15%ほど甘い。今の本番の実力は 85%前後とみるのが正直なところ（全通り買いは73%）。
4. 期待値の基準を上げても解決しない（基準を上げるほど、オッズの下がり方が大きい）。

## 次にやること

- 「確定オッズがいくらになるか」を5分前の時点で予想する仕組みを作り、その予想オッズで期待値を計算する（5分前オッズが3,000レース以上たまったら学習。11/23時点で約2,000レース）。
- それでも100%を超える買い目が残るかどうかを、同じ方法（5分前で決めて確定で払い戻し）で確かめる。
- 本番（エア投票・通知）は変えていない。実際のお金を賭ける判断材料としては、今は「賭けない」。
